# Jstest
## Introduction
Jstest is an anime explorer built with HTML, CSS, and JavaScript, utilizing the AniList GraphQL API.
## Key Features
- Anime search functionality
- Anime details page
- Episode list and player
## Tech Stack
- HTML
- CSS
- JavaScript
## Installation
1. Clone the repository: git clone https://github.com/username/Jstest.git
2. Open the index.html file in a web browser
## Usage
1. Search for an anime using the search bar
2. Click on an anime to view its details
3. Click on an episode to play it
